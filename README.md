# Leveraged Buyout (LBO) Financial Model

## Project Overview
This project presents a 5-year Leveraged Buyout (LBO) financial model developed using Microsoft Excel to evaluate the acquisition of a Specialty Services Business. The model analyzes the financial feasibility of an acquisition financed through a combination of debt and equity, projecting operating performance, debt repayment, and investor returns over a five-year holding period.

## Objectives
- Evaluate the financial feasibility of a leveraged buyout.
- Analyze the impact of debt and equity financing on acquisition returns.
- Project revenue, EBITDA, and Levered Free Cash Flow (LFCF).
- Calculate investment returns using Multiple on Invested Capital (MOIC) and Internal Rate of Return (IRR).
- Understand the relationship between entry valuation, exit valuation, and private equity returns.

## Key Financial Metrics

| Metric | Description |
|---|---|
| EBITDA | Earnings Before Interest, Taxes, Depreciation, and Amortization |
| LFCF | Levered Free Cash Flow |
| MOIC | Multiple on Invested Capital |
| IRR | Internal Rate of Return |
| Entry Multiple | Acquisition valuation based on EBITDA |
| Exit Multiple | Valuation multiple at the end of the investment period |
